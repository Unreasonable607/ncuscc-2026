# 待理解清单

这几天很多操作是照着指示做的，敲了但没真懂。列在这里，一个个补。

## Linux 命令

- [ ] `cp 源 目标` —— 复制文件。第 1、2 关都用它把文件改成程序要的名字
- [ ] `mkdir` / `cd` / `ls -la` —— 建目录、进目录、看目录
- [ ] `find /workspace -type f` —— 递归找文件，`-type f` 表示只找普通文件
- [ ] `grep -r "关键词" 路径` —— 递归搜索含关键词的行
- [ ] `cat 文件` —— 打印文件内容
- [ ] `>` 和 `>>` —— 输出重定向：覆盖 vs 追加
- [ ] `<` —— 输入重定向，比如 `./main < 输入文件`
- [ ] `diff 文件A 文件B` —— 比较差异，没输出就是完全相同
- [ ] `echo $?` —— 看上一条命令的退出码，0 表示成功
- [ ] `wc -c 文件` —— 数文件有多少字节
- [ ] `rm -r 目录` —— 递归删除目录
- [ ] `chmod` —— 改权限，`-x` 去掉执行权限，`755` 是数字写法
